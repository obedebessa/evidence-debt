\section{Data and Code Availability}
\label{sec:availability}

The simulation code, canonical synthetic outputs, repository-observation collector,
frozen age-stratified sample, manual-audit coding, generated tables, and reproduction
instructions are archived at Zenodo as version 1.2.0, DOI
\href{https://doi.org/10.5281/zenodo.21843147}{10.5281/zenodo.21843147}; the
version-independent concept DOI is
\href{https://doi.org/10.5281/zenodo.21841440}{10.5281/zenodo.21841440}. The
development repository is
\href{https://github.com/obedebessa/evidence-debt}{\texttt{github.com/obedebessa/evidence-debt}};
the archival source is tagged \texttt{v1.2.0}. The file
\texttt{MANIFEST.sha256} records a SHA-256 digest for every released artifact, and
\texttt{CITATION.cff} records the version-specific DOI. The frozen observation can
be verified offline; live recollection is separated because public repository state
can change.
